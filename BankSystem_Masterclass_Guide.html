Foundational Concepts You Must Understand

Key paradigms that underpin the entire BankSystem application.
MVC Pattern

Model: Data & business state.
View: Razor HTML rendered to the browser.
Controller: Handles HTTP requests, talks to services, and returns a View or Redirect.

EF Core & LINQ

Deferred Execution: LINQ queries build an Expression Tree. They only hit the database when executed with ToListAsync(), FirstOrDefaultAsync(), etc.

Identity & Auth

Authentication: Who are you? (Cookie check).
Authorization: What can you do? ([Authorize(Roles="Customer")]).

Domain Models & ViewModels (Data Architecture)
Account.cs
  • int Id: Primary Key
  • string AccountNumber: e.g. "CHK4921942"
  • decimal Balance: Current funds (18, 2)
  • string AccountType: "Checking" or "Savings"
  • int CustomerId: Foreign Key to Customer
  • ICollection<Transaction> Transactions: Ledger items
  • ICollection<Card> Cards: Attached debit cards
Customer.cs
  • int Id: Primary Key
  • string UserId: Foreign Key to Identity User
  • string FirstName, LastName: Profile names
  • DateTime DateOfBirth: KYC age verification
  • string? Address: Residential address
  • ICollection<Account> Accounts: Owned accounts
  • ICollection<Loan> Loans: Applied loans
TransferViewModel.cs
  • [Required] int FromAccountId
  • [Required] string ToAccountNumber
  • [Required] [Range(0.01, double.MaxValue)] decimal Amount

Razor Views & Frontend Mechanics
How Views Work in this Project
  • _ViewImports.cshtml: Universally registers @using BankSystem.Web, @using BankSystem.Web.Models, and @addTagHelper *, Microsoft.AspNetCore.Mvc.TagHelpers so every single view can use tag helpers without manual imports!
  • _ViewStart.cshtml: Specifies Layout = "_Layout"; so that all pages automatically inherit the common master layout (sidebar, navbar, stylesheets).
  • _Layout.cshtml: Contains the dark glassmorphic UI shell, navigation drawer, login/logout header buttons, and scripts (Bootstrap 5 & Chart.js).
  • Views/Customer/Dashboard.cshtml: The main financial cockpit. Uses Razor to calculate totals with LINQ: Model.Accounts?.Sum(a => a.Balance), renders active cards, and initializes a Chart.js cash flow graph.
